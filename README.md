# mac-du

macOS 터미널에서 현재 디렉토리의 용량을 시각적으로 보여주는 디스크 사용량 TUI 도구입니다.
하위 파일과 폴더를 디스크 사용량 순으로 정렬해 보여 주므로, 어디서 공간이 많이 쓰이는지 한눈에 파악할 수 있습니다.

> 상태: 개발 초기 단계입니다. 현재는 **디렉토리 목록 조회와 폴더 드릴다운**까지 구현되어 있습니다.

## 요구 사항

- macOS
- Rust 툴체인 (stable)

Rust가 없다면 [rustup](https://rustup.rs)으로 설치합니다.

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## 설치 및 실행

```bash
git clone <저장소 URL>
cd mac-du
cargo run --release
```

용량을 보고 싶은 디렉토리에서 실행하려면 바이너리를 빌드해 PATH에 넣습니다.

```bash
cargo build --release
cp target/release/mac-du /usr/local/bin/   # 필요 시 sudo
cd ~/Downloads && mac-du
```

## 사용법

실행하면 현재 작업 디렉토리(`cwd`)를 기준으로 화면이 그려집니다.

| 키 | 동작 |
| --- | --- |
| `j` / `↓` | 아래 항목으로 이동 |
| `k` / `↑` | 위 항목으로 이동 |
| `l` / `→` / `Enter` | 선택한 폴더 안으로 들어가기 (파일은 무시) |
| `h` / `←` / `Backspace` | 상위 폴더로 올라가기 (떠나온 폴더가 선택된 상태로 열림) |
| `q` / `Esc` | 종료 |

화면 구성:

- **헤더**: 현재 경로와 전체 합계
- **목록**: `크기 · 비율 · 막대 그래프 · 아이콘 · 이름` 순서로, 크기 내림차순 정렬
- **푸터**: 키 도움말. 폴더를 열 수 없으면 빨간색 경고 메시지가 대신 표시됩니다.

폴더는 📁, 파일은 📄로 표시됩니다.
심볼릭 링크는 폴더로 취급하지 않아 들어갈 수 없습니다.

## 용량 계산 방식

- **디스크 사용량 기준**: 파일의 논리 크기(`len`)가 아니라 실제 할당된 블록(`st_blocks × 512`)을 합산합니다. Finder의 "디스크 사용량"과 비슷한 값입니다.
- **폴더**: 하위 항목을 재귀적으로 합산합니다.
- **심볼릭 링크**: 따라가지 않습니다. 순환 참조를 막기 위해서입니다.
- **권한 없는 경로**: 읽을 수 없는 디렉토리는 0 바이트로 집계되며, 오류는 화면에 표시되지 않습니다.

## 프로젝트 구조

```
src/
├── main.rs     # 터미널 초기화, 이벤트 루프, 종료 시 터미널 복구
├── scanner.rs  # 디렉토리 스캔 및 용량 계산 (UI와 무관한 로직)
├── app.rs      # 앱 상태: 항목 목록, 선택 위치, 종료 플래그
└── ui.rs       # ratatui 렌더링 (헤더 / 목록 / 푸터)
```

## 개발

```bash
cargo build            # 디버그 빌드
cargo run --release    # 실행 (용량 계산이 빠릅니다)
cargo clippy           # 린트 (clippy 컴포넌트 필요: rustup component add clippy)
```
