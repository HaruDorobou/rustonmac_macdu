# mac-du

macOS 터미널용 디스크 사용량 뷰어입니다. 폴더 아래를 용량 순으로 보여 주고, 폴더로 들어가거나 이름으로 찾으면서 큰 항목을 찾습니다. 삭제 기능은 없습니다. 찾은 것은 Finder에서 열거나 경로를 복사해서 다른 곳에서 처리합니다.

## 설치

macOS와 Rust 1.85 이상이 필요합니다.

```bash
git clone https://github.com/HaruDorobou/rustonmac_macdu.git
cd rustonmac_macdu
cargo install --path .
```

`mac-du`로 실행합니다. 설치하지 않고 `cargo run --release`로 실행할 수도 있습니다.

## 사용법

```bash
mac-du [옵션] [경로]
```

```bash
mac-du               # 현재 폴더
mac-du ~/Downloads   # 지정한 폴더
```

| 키 | 동작 |
| --- | --- |
| `j` `k` (`↓` `↑`) | 위아래 이동 |
| `gg` (`Home`) · `G` (`End`) | 맨 위 · 맨 아래 항목으로 |
| `Ctrl-d` `Ctrl-u` (`PageDown` `PageUp`) | 반 화면 · 한 화면씩 아래/위로 |
| `/` | 지금 폴더 목록에서 이름 검색. 치는 동안 하이라이트가 따라가고, `Enter`로 확정, `Esc`로 취소 |
| `f` | 찾기 화면: 폴더 아래 전체에서 가장 큰 파일 순위, 이름으로 찾기 (아래 "찾기" 참고) |
| `n` `N` | 마지막 검색어와 일치하는 다음 · 이전 항목으로 (끝에서 처음으로 이어짐) |
| `l` `Enter` (`→`) | 폴더 안으로 들어가기 |
| `h` `Backspace` (`←`) | 상위 폴더로 |
| `r` | 지금 폴더 아래를 다시 스캔 |
| `w` | 감시 켜기/끄기 (`+` `-`로 간격 조절). `/`, `/Users`, `/Users/이름`처럼 얕은 폴더에서는 매번 아래 전체를 다시 읽으므로 확인 팝업이 뜹니다 |
| `p` | 위쪽 폴더까지 미리 스캔 |
| `y` | 하이라이트된 항목의 전체 경로를 클립보드에 복사 |
| `Y` | 지금 보고 있는 폴더의 경로를 클립보드에 복사 |
| `o` | 하이라이트된 항목을 Finder에서 선택해 보여 주기 |
| `O` | 지금 보고 있는 폴더를 Finder에서 열기 |
| `u` | 크기 단위 순환: 자동 → K → M → G → T |
| `s` | 기준 전환: 1024 (`KiB`, `MiB`, ...) ↔ 1000 (`KB`, `MB`, ... Finder와 같음) |
| `S` | 정렬 순환: 크기 큰 순 → 이름순 → 크기 작은 순. 기본이 아닌 순서는 목록 테두리에 표시됩니다 |
| `i` | 하이라이트된 항목의 정확한 바이트 수 보기 |
| `e` | 읽지 못한 경로 목록 |
| `?` | 키 도움말 팝업 |
| `q` `Esc` | 종료 (팝업이 열려 있으면 닫기) |
| `Ctrl-c` | 어디서든 바로 종료 |

| 옵션 | 설명 |
| --- | --- |
| `-j`, `--threads N` | 스캔 스레드 수. 기본은 코어 수이고 최대 16 |
| `-r`, `--root DIR` | DIR 전체를 먼저 스캔하고, 화면은 시작 폴더에서 시작 |
| `--si` | 크기를 1000 기준으로 표시하며 시작 (기본은 1024 기준) |
| `-w`, `--watch SEC` | 시작할 때부터 SEC초마다 현재 폴더를 다시 스캔 (2 이상) |

## 동작

- 폴더를 스캔하면 그 아래 전체의 크기를 메모리에 저장합니다. 폴더를 오가는 것은 저장된 결과를 보여 주므로 다시 읽지 않습니다.
- 저장된 결과는 파일이 바뀌어도 자동으로 갱신되지 않고, 폴더에 다시 들어가도 바뀌었는지 확인하지 않습니다. 대신 헤더에 `(합계: 12.3 GiB · 3분 전 스캔 · 0.21초 소요)`처럼 지금 보는 데이터를 언제 읽었는지 표시됩니다. 오래됐으면 `r`로 현재 폴더 아래를 다시 읽으세요.
- 일부만 다시 읽거나 범위를 넓혀서 여러 스캔의 결과가 섞인 폴더는, 그 폴더의 목록을 읽은 스캔 하나를 기준으로 표시합니다. `소요`는 그 스캔이 걸린 시간이고, 아래 폴더 중에는 더 오래됐거나 더 새로운 부분이 있을 수 있습니다.
- 시작 폴더보다 위로 올라가면 이미 읽은 부분은 두고 나머지만 읽습니다. `p`나 `--root`로 위쪽 폴더까지 미리 스캔해 둘 수도 있습니다. 범위가 넓을수록 첫 스캔 시간과 메모리 사용량이 늘어납니다.
- 크기는 디스크에 실제로 할당된 크기라서 파일 길이와 다를 수 있습니다. 심볼릭 링크는 따라가지 않습니다.
- `o`로 `.`으로 시작하는 숨김 항목을 열면, 푸터에 Finder에서 `⌘⇧.`로 숨김 파일을 표시하라는 안내가 나옵니다.

## 찾기

`/`는 지금 보는 폴더의 목록 안에서 이름을 찾아 하이라이트를 옮기고, `f`는 그 폴더 아래 전체(하위 폴더 모두)를 훑습니다.

- `f`를 열면 먼저 가장 큰 파일 순위가 나옵니다. `/`를 누르고 이름 일부를 치면 이름에 그 글자가 들어 있는(대소문자 무시) 파일과 폴더가 큰 순서로 나옵니다.
- `Tab`은 파일+폴더 → 파일만 → 폴더만을 바꿉니다. 직접 고른 종류는 검색어를 바꿔도 유지됩니다.
- 위쪽에 일치한 건수와 합계가 나옵니다. 일치한 폴더 안에 또 일치한 항목이 있으면(`node_modules` 안의 `node_modules`) 안쪽은 합계에 더하지 않고, 그 행에 `↳ 위 항목에 포함`을 붙입니다. 읽지 못한 경로가 있으면 합계 앞에 `≥`가 붙습니다.
- 목록에는 큰 것부터 500건까지만 보여 주고, 건수와 합계는 전부 셉니다.
- `Enter`는 그 항목이 있는 폴더로 이동해 항목에 하이라이트를 둡니다. `Esc`로 닫습니다.
- 이미 스캔해 둔 결과만 훑고 디스크는 다시 읽지 않습니다. 결과가 얼마나 오래됐는지는 헤더의 스캔 시각과 같습니다.

## 한글 자판

한글 입력 상태에서도 단축키가 동작합니다. `ㅓ`는 `j`, `ㅏ`는 `k`처럼 같은 위치의 영문 키로 처리하고, `hl`처럼 연달아 눌러서 `ㅚ`로, `gk`처럼 `하`로 합쳐진 글자도 다시 키 순서대로 풉니다. 검색어(`/`, 찾기의 이름 입력)를 칠 때는 한글이 그대로 들어갑니다.

- 단축키는 영문 자판이 기준입니다. 한글 상태에서 단축키를 처음 누르면 그 사실을 푸터에 한 번 알려 줍니다.
- 글자를 입력하는 칸(`/` 검색 줄, 찾기 화면)에는 지금 선택된 입력 소스가 `[한글]` `[영문]` `[기타]`로 표시됩니다. 한영 전환 키만 눌러도 바로 바뀝니다. macOS의 입력 소스 API로 읽기만 하며 별도 권한은 필요 없습니다. 영문과 한글 말고는 모두 `기타`입니다.
- 터미널은 Shift를 눌러도 `ㅎ`을 `ㅎ`으로 보내므로 `G` `S` `Y` `N` 같은 대문자 키는 구분하지 못하고 소문자로 처리됩니다. 이 키들은 영문으로 바꿔서 누르세요. (Shift를 누르면 모양이 달라지는 `ㅒ` `ㅖ` `ㅃ` `ㅉ` `ㄸ` `ㄲ` `ㅆ`은 구분되어, `ㅒ`는 `O`(현재 폴더를 Finder에서 열기)가 됩니다.)
- 키 입력이 한글 입력기가 글자를 확정할 때 넘어오는 방식이라 반응이 한 박자 늦을 수 있습니다.

## 크기 표시

기준과 단위를 따로 고릅니다. 같은 폴더(12,158,771,200 바이트)가 이렇게 보입니다.

| 기준 | 자동 | `M` | `G` | `T` |
| --- | --- | --- | --- | --- |
| 1024 (기본, `du -h`와 같음) | `11.3 GiB` | `11,595.5 MiB` | `11.32 GiB` | `0.011 TiB` |
| 1000 (`s`, Finder와 같음) | `12.2 GB` | `12,158.8 MB` | `12.16 GB` | `0.012 TB` |

- `s`가 기준을, `u`가 단위를 정합니다. 두 설정은 서로 영향을 주지 않고, 폴더를 옮겨도 유지되지만 저장되지는 않습니다. 시작할 때부터 1000 기준으로 보려면 `--si`를 씁니다.
- 단위를 고정하면 모든 행이 같은 단위로 나와서 숫자를 바로 비교할 수 있습니다. 소수점 자리는 K·M은 1자리, G는 2자리, T는 3자리입니다.
- 고정 단위에서 값이 너무 커서 12자를 넘으면 그 값만 자동 단위로 보여 줍니다. 단위 라벨이 항상 붙으므로 섞여도 구분됩니다.
- 0이 아닌데 표시 자릿수보다 작으면 `<0.01 GiB`처럼 표시해서 비어 있는 것과 구분합니다.
- `i`는 하이라이트된 항목의 정확한 값을 두 기준으로 보여 줍니다. 예: `12,158,771,200 B (11.32 GiB · 12.16 GB)`.

## 감시 모드

`w`를 누르면 보고 있는 폴더를 일정 간격으로 다시 읽고, 직전 스캔과 달라진 항목에 `▲ +120.0 MiB`, `▼ -3.0 MiB`, `NEW`를 붙입니다. 간격은 `+` `-`로 바꿉니다. 최소 2초이고 최대는 제한이 없습니다. 지금 보는 폴더를 `r`이나 감시로 다시 읽어 본 시간의 2배보다 짧은 간격으로는 돌지 않고, 그럴 때는 `(스캔이 오래 걸려 N초)`가 표시됩니다. 폴더를 옮기거나 위로 올라가면 그 폴더를 다시 읽어 보기 전까지는 설정한 간격 그대로입니다.

`/`, `/Users`, `/Users/이름`처럼 루트에 가까운 폴더(경로 깊이 0~2)에서 켜면 매번 아래 전체를 다시 읽으므로 확인 팝업이 먼저 뜹니다. 감시는 그대로 켜집니다.

## 읽지 못한 경로

권한이 없어 읽지 못한 폴더는 크기를 0으로 계산합니다. 목록에 `⚠ 읽지 못함`이 붙고 합계 앞에 `≥`가 표시됩니다. `e`를 누르면 경로와 사유(`허용 안 됨`, `권한 없음`)를 볼 수 있습니다. macOS가 접근을 막는 사진·음악 라이브러리나 휴지통이 여기에 나옵니다.

## 개발

```bash
cargo test
cargo build --release
```

`src/`는 `main.rs`(진입점과 키 처리), `cli.rs`(옵션), `scanner.rs`(스캔), `app.rs`(상태와 폴더 이동), `ui.rs`(화면), `find.rs`(찾기), `hangul.rs`(한글 자판을 영문 키로), `inputsource.rs`(지금 선택된 입력 소스 읽기), `clipboard.rs`(`pbcopy` 호출), `finder.rs`(`open` 호출), `units.rs`(크기 표기)로 나뉩니다.
